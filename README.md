# Clocks

Analog clock experiments for calendar scales, personal time, decimal time, and matched city time.

## Pages

- [Clock scales](https://pcleddy.github.io/clocks/) - calendar, personal, and decimal analog clocks.
- [City match clocks](https://pcleddy.github.io/clocks/timezone.html) - compare 24-hour clocks across major world cities.

## City Match

The city page starts with Albuquerque and Berlin. Search any city field to swap in one of 50 major cities, use the time input or hour buttons to change the meeting time, and every clock stays matched to the same instant. Add clocks for up to 4 cities, or remove extras back down to 2.

Use **Find shared waking time** to jump to the next whole-hour slot when every displayed city is between 08:00 and 21:59 local time. Press it again to cycle to the next matching slot.
